# Touhou Project — Учебный веб-сайт

Небольшой многостраничный информационный сайт, посвящённый вселенной японских игр **Touhou Project**. Проект создан на чистом HTML с использованием встроенных стилей (CSS) в рамках школьного задания по информатике.

## Структура проекта

* `index.html` — главная страница: введение во вселенную, лор мира Генсокё, таблица знаковых игр серии, интересные факты и навигация по сайту.
* `reimu.html` — страница главной героини **Рейму Хакурей** (двухколоночная вёрстка с портретом слева и текстом справа).
* `marisa.html` — страница волшебницы **Марисы Кирисаме** (трёхколоночная симметричная вёрстка с портретом по центру).
* `cirno.html` — страница ледяной феи **Чирно** (зеркальная вёрстка с текстом слева и портретом справа).
* `scarlet.html` — совместная страница сестёр **Ремилии и Фландр Скарлет** (разделение на две полноценные колонки с индивидуальным оформлением).
* `fan_content.html` — галерея фанатского творчества: популярные мемы, гифки, фан-арты и музыкальные ремиксы.

## О вселенной и особенностях дизайна серии

В играх жанра *данмаку* («пулевой ад») экран заполнен тысячами ярких снарядов. Автор серии **ZUN** выбрал сказочных героинь в пышных платьях и ярких костюмах, чтобы фигурку персонажа было легко разглядеть на тёмном фоне среди вспышек и выстрелов, а также чтобы игра визуально отличалась от типичных стрелялок про космические корабли и роботов. Сюжет строится вокруг синтоистских жриц, волшебниц и духов из японских легенд, где женские образы традиционно занимают центральное место.

## Как запустить локально

1. Скачайте все файлы репозитория в одну папку (кнопка **Code → Download ZIP**).
2. Распакуйте архив, сохраняя все HTML-файлы, изображения и аудио в единой директории.
3. Откройте файл `index.html` в любом современном браузере.
